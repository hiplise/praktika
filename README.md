# Приложение для ведения бюджета (Учебная практика)

Консольное приложение на языке Python для планирования личных финансов, учета накоплений и расчета сроков достижения финансовых целей.

## Описание версий

* **Версия 1 (`budget_v1.py`, `budget_v1.db`)** — базовая реализация с использованием базы данных SQLite. Позволяет учитывать доходы, расходы и рассчитывать срок накопления на цель.
* **Версия 2 (`budget_v2.py`, `budget_v2.db`)** — расширенная версия с динамическим циклическим моделированием. В расчетах учитываются ежемесячная капитализация процентов по вкладу и индексация стоимости цели с учетом инфляции.

## Стек технологий
* Python 3
* SQLite3

## Запуск проекта
1. Скачайте файлы нужной версии из репозитория.
2. Запустите скрипт через терминал или среду разработки:
   ```bash
   python budget_v2.py
   ```
